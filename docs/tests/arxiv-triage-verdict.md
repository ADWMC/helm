# 60 篇筛选：哪些有用

判断标准：**能不能改变 helm 的行为**。只给能落地的，不做文献综述。

## 第一梯队：直接可用（4 篇）

### 1. `2605.09698` Ambig-DS — 最有价值，因为它量化了失败的代价

**核心发现**：5 个前沿 code agent，在含糊任务上 **39–63% 提交了错误的预测目标，
且没有一个表示过疑问**。

论文给这个失败模式起了名字：**unflagged misframing** —— 产物是可执行的、
格式正确的、评估器接受的，但它**悄悄解决了另一个问题**，下游没有任何信号能发现。

**为什么这条最重要**：它证明"沉默地做错"比"报错"危险得多。helm 的
`done_when` + `finish_basis` 只能判"我做完了吗"，**判不了"我做的是对的那件事吗"**。

**但有个坏消息（第 iii 条）**：

> agents cannot reliably tell when to use it: **permissive prompts induce over-asking
> on clear tasks, while conservative prompts induce silent defaulting on ambiguous ones**

**即：让模型自己判断"该不该问"，两个方向都会失败。** 这直接否定了"给个提示让它
自己拿捏"的做法 —— 必须给**外部判据**，不能靠模型自觉。

### 2. `2608.19202` Active Inference as Context Acquisition (OQA) — 最严谨的判据

是 `2502.04485` 的形式化加强版。把"问 / 默认假设 / 去查"统一成一个决策：

```
内层：更新对潜在任务状态的信念
外层：在 {context action, task action, stop action} 中选，最小化带成本的期望自由能
确定性情形下，认知项退化为期望信息增益 (EIG)
```

**关键增量**：`2502.04485` 只在"候选问句"里挑；**OQA 把"问人"和"去检索/调工具"
放在同一个决策空间里比较**。这正好对应我上次跟你说的界 —— 能查到的别问人。
论文给了**精确后验 + 动态规划 oracle**，所以有**可达上界**可对照。

**代价**：`2592.04485` 的 EIG 是纯算术，OQA 需要维护信念分布。
量大时不一定划算。**建议先抄 EIG，OQA 作为设计参照。**

### 3. `2609.30289` HiCoMER — 有效性感知检索

**核心**：扁平池按相似度检索会捞出**过时或矛盾**的记忆。修法：**先过滤有效性，再排序**。

**为什么有用**：helm 的 `tool-memory` 已有 `status=stale` 不注入 + 唯一索引取代，
但 `verify()` 靠**重跑探针**判失效 —— 表达不了"结论被后来的证据推翻"。
HiCoMER 处理的正是后者。

### 4. `2603.26233` Ask or Assume? — 唯一有实测收益的

欠定 SWE-bench 上 **69.40%**，接近全指定指令水平。且实测**校准会自然出现**
（简单任务少问、复杂任务主动问）。

**注意与 Ambig-DS 的张力**：这篇说多 agent 结构能校准，Ambig-DS 说单靠提示
无法可靠判断。**两者不矛盾** —— 前者是**解耦出的独立角色**（外部判据），
后者是**同一个 agent 自己拿捏**（自觉）。结论一致：**要外部判据。**

## 第二梯队：机制可借鉴（3 篇）

### 5. `2510.00615` ACON — 压缩准则用对比反馈迭代

token 降 26–54% 且成功率升。**但 helm 已有 `online-context-compact`，
成本模型比它细**（算的是收支平衡请求数，不是固定 λ）。真缺口只有一个：
**压缩指令 `BOUNDARY_COMPACTION_INSTRUCTIONS` 是写死的常量**，ACON 的做法是拿
"未压缩成功 / 压缩后失败"的对比样本去迭代它。

### 6. `2512.15374` SCOPE — Dual-Stream：战术记忆 + 战略记忆

**机制**：把准则按流路由 —— **战术记忆**（即时纠错）vs **战略记忆**（持续精炼，
带冲突消解、包含剪枝、合并）。框架是**在线优化**：从执行轨迹合成准则、自动进化提示。

**为什么值得看**：这正是 helm 缺的"压缩准则反馈回路"的一个具体设计，
而且它**明确处理了准则冲突** —— 多条准则互相矛盾时怎么办。

### 7. `2604.09747` ADAM — 用熵做自适应查询来攻击记忆

攻击视角，但机制可直接反用：**用数据分布估计 + 熵引导查询**最大化信息泄漏。

**为什么列它**：helm 的 tool-memory 是会跨会话累积的，里面有真实资产信息
（路径、口令位置、靶场拓扑）。`2502.13172` (MEXTRA) 和这篇是同类风险。
**这是安全 side 该看的两篇** —— 不是 agent 能力，是 agent 自身被提取。

## 明确没用的（按理由分类）

**跑偏领域**：`2601.13114` IntAgent（NWDAF/电信网）、`2501.08760` INTA（网络配置转换）、
`2510.018550` JAUNT（QoE 路由）、`2506.04980` 工业自动化、`2402.01698` 城市规划、
`2401.15688` 文生图规划、`2504.11571` 平面设计。**都是 "intent" 这个词命中的，
但讲的是工业/网络/图形领域的意图，与理解用户要什么无关。**

**纯训练方法**：`2601.01885` AgeMem（三阶段 RL + step-wise GRPO）、`2605.21768`
Memory-R2（GRPO 信用分配）、`2406.11132` RePrompt。**要微调，helm 用不上。**
（AgeMem 的唯一可搬点：记忆操作工具化，但 helm 的 store 已是库调用。）

**综述/立场/基准，无机制**：`2510.26493` Context Engineering 2.0（综述，还夹了马克思）、
`2502.06975` 情景记忆（position paper）、`2511.20857` Evo-Memory（基准）、
`2608.15008` memory substrate 评测、`2511.01527` TPS-Bench、`2606.04874` Planning
Benchmark、`2601.15487` MiRAGE（RAG 评测集生成）。

**对话检索/推荐的老论文（2021-2022）**：`2101.06327`、`2201.00235`、`2201.08742`、
`2109.12451`、`2105.04774`、`2410.19692` AGENT-CQ。**年代对不上**，且场景是
搜索/推荐/车载语音，不是 agent 任务。**唯一还有参考价值的是 `2201.08742`** ——
它建了个经济学模型，论证"要多少反馈取决于反馈的收益与成本之比"，
这是 OQA 成本项的前身。

**工程/系统而非技术**：`2608.23992` SCOUT（MCP 网关工具发现，2000+ 工具）、
`2512.24615` Youtu-Agent（框架）、`2603.09022` MEMO（游戏）、`2502.04485` 的
场景受限（只在 20 questions 和代码生成上验）。

**安全但与 helm 能力无关**：`2605.16976` Intent-to-Execution Integrity（position，
但**值得 helm 收一条原则**：现有防御都假设工具可信，第三方 skill 生态打破这个假设）、
`2506.07524` TAI3（API 压力测试）、`2603.20976` 对抗意图检测。

## 结论

**真正值得动手的只有一条线**：

```
缺的能力：判断"我做的是对的那件事吗"
├─ 判据从哪来 → 2608.19202 (OQA) / 2502.04485 (EIG)
├─ 为什么必须外部判据 → 2605.09698 (Ambig-DS 第 iii 条：模型自己拿捏必失败)
├─ 结构怎么做 → 2603.26233 (解耦独立角色，69.40%)
└─ 收益多大 → Ambig-DS 实测 39-63% 会做错目标且不自知
```

**其余 56 篇：要么跑偏领域，要么要训练，要么只是基准。**
ACON/SCOPE 那 3 篇属于"helm 已有 80%，补最后一个反馈回路"，
优先级低于上面这条主线。
